Installation

  1. Use a clean Perfect Dark (USA) v1.1 big-endian .z64 ROM.
  2. Verify source MD5: e03b088b6ac9e0080440efed07c1e40f.
  3. Apply one edition's .xdelta patch with a compatible xdelta patcher. Keep your original ROM.
  4. Use an Expansion Pak (8 MiB) on original Nintendo 64 hardware. Output is fixed at 640×480i; the Hi-Res menu item is intentionally inactive.

The optional 2,048-byte Dark EEPROM provides 100% unlocks with stock settings and controls. Cheats are unlocked, not activated. It does not force controller style 1.2. Back up your existing save before using it.

Test status

v87 has user-confirmed CamSpy behavior on Analogue 3D. v88 has software control tests and an original-N64 intro boot check; its Analogue 3D check is pending. These checks do not establish exhaustive compatibility or a guaranteed frame rate.
