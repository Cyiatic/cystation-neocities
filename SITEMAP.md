# CyStation sitemap and flow

Primary navigation: **Station · 480i Patches · Render Restore · Timeline · Directory**.

| Area | Route | Role |
| --- | --- | --- |
| Station | / | Short introduction, released PD/TND entries, featured preservation work |
| 480i Patches | /patches | Released and in-development project gallery |
| TND6480i | /tnd6480i/ | Game-style file select and dossier; return in Options |
| PD6480iPerf | /pd6480iperf/ | Animated game-style menu; return in Options |
| Why 480i? | /why-480i | Background guide, linked from home and patches |
| Render Restore | /render-restore.html | Separate preservation archive |
| Conker Skyboxes | /render-restore/conker-skyboxes.html | Panorama viewer, expandable sources/research |
| Tools of the Trade | /render-restore/tools-of-the-trade.html | Preservation record |
| Timeline | /projects | Dated history linking to relevant project pages |
| Directory | /navigation | Complete human-readable sitemap |
| Supporting pages | /aboutme, /credits, /links | Footer/directory destinations |

Visitors enter a game's native presentation directly. Quick links open TND #q-branch or PD #editions for downloads and installation. Native Options return to /patches#tnd6480i or /patches#pd6480iperf so the correct selection is restored. No general site header overlays the game menus.

Patches and preservation stay separate. Conker's patch status links to its skybox viewer, and the viewer links back to the related patch status. GitHub and Internet Archive remain supporting source/download/archive destinations.

/sitemap.xml lists the 13 canonical pages. Practice routes remain development copies and carry noindex. Use the canonical project folders for subsequent visitor-facing changes.
