Patch information

TND6480i · g1mcfix4

Tomorrow Never Dies 64 Expanded 11-24 with Cyiatic's 480i patch. This dossier uses menu assets from that build.

Download the supplied xdelta patch

Patch file: TND64_Expanded_11-24_480i-Cyiatic.xdelta. Format: xdelta / VCDIFF. Target build: g1mcfix4. Later project releases are separate builds.

Installation

  1. Start with your own stock GoldenEye 007 (USA).z64 dump. Source MD5: 70c525880240c1e838b8b1be35666c3b.
  2. Apply the xdelta to that source with an xdelta-compatible patcher. Save to a new file.
  3. Verify the output MD5: fa93be061c59ef5cabad24fbf5f66b39.
  4. Use an Expansion Pak / 8 MB and the project's EEPROM 4K save setting.

Menu music: “Briefing” by Clasiku, from the Tomorrow Never Dies 64 album. Music is on when the page opens and loops through file selection, menus and briefings. If your browser blocks autoplay, selecting a folder starts it. Switch music off in OPTIONS; it stays off until you reload. Music and SFX have separate controls.

The GoldenEye decompilation informs menu geometry, glyph rendering and sound events. KholdFuzion's GoldenEye status page was the original website reference.

The menu textures, model, fonts and cursor come from the supplied patch. The layout and framing follow the 480i captures taken on Analogue 3D with progressive output and horizontal scaling. Compare game text shows the four original briefings for visual comparison. Sound effects come from stock GoldenEye 007 without added reverb. Your display handles 1080i output; this page adds no scanline effect. Console filtering and the full audio mixer remain approximations.
